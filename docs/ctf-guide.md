## 第二部分：CTF 五大赛道技术全景

### 1. Web 渗透：从前沿框架到深度链条
- 基础层：HTTP/HTTPS 协议深解、SQL 注入、XSS、CSRF、SSRF、文件上传漏洞。
- 进阶层：PHP/Java/Node.js 反序列化、SSTI 模板注入、原型链污染、JWT 攻击、OAuth 认证缺陷。
- 工具箱：Burp Suite Pro、Caido、Sqlmap、AntSword、Beautifier。

### 2. Reverse 逆向工程：二进制世界的考古学家
- 静态分析：汇编语言精读、C/C++ 数据结构还原、IDA Pro 深度使用、Ghidra 反编译。
- 动态调试：x64dbg 单步调试、硬件断点追踪、GDB-GEF 内存监控。
- 混淆与对抗：反调试检测突破、花指令清除、SMC 自修改代码、UPX/VMP 壳分析。

### 3. Pwn 二进制漏洞利用：操控 CPU 与内存的最极致艺术
- 栈溢出系列：Ret2text、Ret2shellcode、Ret2libc、ROP 链构造。
- 格式化字符串：任意内存读写、GOT 表覆写劫持控制流。
- 堆利用艺术：Fastbin Dup、Unsorted Bin Attack、House of Force / Lore / Spirit。
- 工具箱：Pwntools、Pwndbg、Ropper、ROPgadget、Checksec。

### 4. Crypto 密码学：纯粹数学逻辑构建的防御壁垒
- 古典密码：凯撒、维吉尼亚、仿射密码、隐写编码。
- 对称加密：DES/AES 算法原理、CBC 字节翻转攻击、Padding Oracle。
- 非对称加密：RSA 数论攻防（共模攻击、低指数攻击、Wiener 攻击）、ECC 椭圆曲线。
- 工具箱：SageMath、PyCryptodome、CyberChef、FactorDB。

### 5. Misc 杂项与数字取证：包罗万象的数字侦探
- 图片隐写：LSB 隐写、PNG 文件头修复、盲水印提取、F5 隐写。
- 流量分析：Wireshark PCAP 包抓包重组、TLS 解密、工业控制协议（Modbus/S7）分析。
- 内存与磁盘取证：Volatility 内存转储镜像解析、FTK Imager 电子数据提取。
