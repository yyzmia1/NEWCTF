STAGE-02 靶向破茧期 · 赛题逆推原理

第二阶段：以 CTF 为练兵场（五大方向与教程汇总）

选方向建议：初学先从 Web 或 Misc 入手；对底层逻辑/C语言感兴趣主攻 Reverse 或 Pwn；数学功底好攻 Crypto。先体验全貌，再专精 1~2 个方向。

必存权威百科： Hello CTF — 零基础入门必读手册 ↗ · CTF Wiki — 网络安全竞赛权威知识库 ↗
WEB SECURITY 入门推荐 · 难度: ★★

1. Web（网页攻防）

接触网页应用交互、请求参数、身份验证与常见 Web 漏洞。做题时打开浏览器开发者工具（F12）看一次请求与响应，再逐步使用抓包神器 Burp Suite，自然掌握 HTTP 协议与常见漏洞利用。

核心工具链
Burp Suite 浏览器 F12 AntSword 蚁剑 SQLmap Postman

MISC FORENSICS 趣味探索 · 难度: ★★

2. Misc（安全杂项与数字取证）

涵盖文件分析、各类编码转换、隐写术（图片/音频隐写）、网络流量包深度分析与数字取证。非常适合零基础培养查线索与安全工具手感；分析流量包过程中自然掌握 TCP/IP 协议与 Wireshark。

核心工具链
Wireshark 010 Editor Binwalk CyberChef Volatility

CRYPTOGRAPHY 数学机理 · 难度: ★★★

3. Crypto（密码学）

围绕编码变换、异或运算、古典密码、数论基础（欧几里得、模运算、大数分解）以及现代密码算法（RSA、AES、ECC）的安全缺陷展开，经常使用 Python 编写自动化解密脚本。

核心工具链
Python (gmpy2) SageMath CyberChef RsaCtfTool PyCryptodome

REVERSE 逆向剖析 · 难度: ★★★★

4. Reverse（逆向工程）

把编译好的二进制程序“拆开”，通过反汇编与反编译还原核心逻辑。理解汇编指令与内存，配合 IDA Pro、Ghidra 进行反编译静态分析，配合 x64dbg、GDB 等工具进行动态调试。

核心工具链
IDA Pro Ghidra x64dbg GDB dnSpy (.NET) angr

PWN BINARY 底层漏洞利用 · 难度: ★★★★★

5. Pwn（二进制漏洞利用）

深入程序底层内存布局（栈溢出、Ret2text、ROP 链构造、堆利用 UAF）与 Linux 运行机制，寻找并利用二进制漏洞劫持控制流获取系统 Shell 权限。

核心工具链
pwntools (Python) GDB (pwndbg) checksec ROPgadget one_gadget

养成写 Writeup（解题复盘笔记）的习惯：四步法标准模板

建议使用 Markdown 语法，配合 Obsidian / Typora / 语雀 / 飞书文档 记录。每道题做完简单记录以下四点：
01
题目与线索
给了什么文件、请求界面或提示？切入点在哪里？
02
解题推进过程
关键观察点、使用的命令、脚本参数与推进步骤。
03
核心漏洞原理
考查哪个安全漏洞或算法机制？为什么利用有效？
04
复盘与知识盲区
卡在何处？补齐了哪个盲区？下次遇到特征先查什么？

网络安全极客公约与法律红线

知其黑，守其白 —— 技术本无善恶，法律与敬畏是唯一的准绳
🔍

探究底层原理，独立排查报错

深入理解操作系统与网络协议底层机制。做题遇到报错先查官方文档与日志，绝不死背参数当“脚本小子”，坚决杜绝盲目求答案的“伸手党”思维。

法律绝对红线

恪守法律红线，绝不越雷池一步

《中华人民共和国网络安全法》第二十七条明文规定：任何技术学习与切磋必须严格限制在已获授权的合法靶场或本地沙盒环境中进行。严禁对未获书面授权的学校内网或互联网任何真实资产发起扫描、探测或漏洞利用。
